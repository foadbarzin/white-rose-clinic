# پیش‌نمایش محلی — White Rose Clinic V2

این سند نحوه اجرای پیش‌نمایش محلی رابط کاربری و منطق سرور را توضیح می‌دهد. پیش‌نمایش **فقط برای توسعه/بازبینی** است و بخشی از محصول منتشرشده در Google Apps Script نیست.

## پیش‌نیاز
- Node.js 18+ (فقط برای اجرای پیش‌نمایش)
- بدون نیاز به حساب Google، Apps Script API، `clasp login` یا Google Sheet

## اجرا
```bash
npm run preview        # سرور پیش‌نمایش روی http://127.0.0.1:8787
npm run preview:check  # تست سلامت محیط پیش‌نمایش (بدون اجرای سرور)
```
تغییر پورت و اطلاعات ورود (اختیاری، فقط برای پیش‌نمایش):
```bash
PORT=8899 PREVIEW_ADMIN_USER=admin PREVIEW_ADMIN_PASSWORD='YourDemoPass#1' npm run preview
```
در PowerShell:
```powershell
$env:PORT=8899; $env:PREVIEW_ADMIN_PASSWORD='YourDemoPass#1'; npm run preview
```

- نام کاربری پیش‌فرض: `admin` — رمز پیش‌فرض: `Preview#12345` (فقط برای همین محیط موقت).
- در داده نمونه کاربران `operator1` و `doctor1` هم وجود دارند.

## چه چیزی واقعی است؟
- `src/Client_Index.html`, `Client_App.html`, `Client_Styles.html`, `Client_Logo.html` بدون تغییر سرو می‌شوند؛ قالب‌ها (`include` / `JSON.stringify`) همانند `doGet` ارزیابی می‌شوند.
- تمام فایل‌های `.gs` بارگذاری و اجرا می‌شوند: احراز هویت، نشست، مجوزها، مشتریان، فاکتور، تخفیف، پرداخت، پورسانت، هزینه/درآمد، گزارش‌ها و AuditLog.

## چه چیزی شبیه‌سازی می‌شود؟
| سرویس Apps Script | جایگزین در پیش‌نمایش |
|---|---|
| `SpreadsheetApp` | شیت‌های درون‌حافظه (`tools/preview/mock.js`) |
| `Utilities` (UUID/hash/Base64/تاریخ) | Node `crypto` و تاریخ تهران |
| `CacheService` | Map درون‌حافظه |
| `LockService` | قفل بی‌اثر (تک‌رشته‌ای) |
| `PropertiesService` | آبجکت درون‌حافظه |

## داده نمونه
با هر بار اجرا، داده‌های نمونه از طریق **سرویس‌های واقعی** ساخته می‌شوند (نه درج مستقیم در شیت):
- ۳ پزشک، ۲ اپراتور، ۶ خدمت، ۷ مشتری
- ۷ فاکتور با وضعیت‌های `paid` / `partially_paid` / `issued` / `draft` / `pending_discount_approval` / `void`
- ۱۳ رکورد پورسانت در وضعیت‌های `paid` / `payable` / `calculated` / `void`
- هزینه‌ها و درآمد متفرقه ماه جاری

همه داده‌ها با بستن/ری‌استارت سرور از بین می‌روند.

## محدودیت‌ها و نکات شناخته‌شده
- این محیط **جایگزین تست در Google Apps Script نیست** (محدودیت‌های واقعی CacheService، سهمیه‌ها و سانیتایزر HTML شبیه‌سازی نمی‌شوند؛ تفاوت TTL کش و ذخیره تنظیمات در گزارش بررسی پروژه ثبت شده است).
- ذخیره تنظیمات در وضعیت فعلی کد خطا می‌دهد (ستون `id` در شیت `Settings` وجود ندارد)؛ این رفتار عیناً در پیش‌نمایش هم دیده می‌شود.
- ستون مشتری در فاکتورها و ذینفع در پورسانت‌ها در UI فعلی UUID نشان می‌دهد.
- `CacheService` واقعی سقف ۶ ساعت دارد؛ پیش‌نمایش این محدودیت را اعمال نمی‌کند.

## امنیت
- سرور فقط روی `127.0.0.1` گوش می‌دهد و از شبکه خارجی قابل دسترسی نیست.
- هیچ توکن، Script ID، Spreadsheet ID واقعی یا رمز واقعی در این پوشه وجود ندارد؛ مقادیر پیش‌فرض صرفاً دموی محلی هستند.
- این پوشه در `.claspignore` (`tools/**`) قرار دارد و هرگز به Apps Script ارسال نمی‌شود.

## توقف و عیب‌یابی
- توقف: `Ctrl+C` در ترمینالی که سرور را اجرا کرده است.
- اگر پورت اشغال بود، `PORT=8899 npm run preview` را اجرا کنید.
- خطای `EADDRINUSE` یعنی نمونه‌ای از پیش‌نمایش از قبل در حال اجراست.
- برای بازبینی سریع بدون مرورگر: `npm run preview:check`
